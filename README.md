# 🛒 Amazon Clone 2025

A responsive **Amazon Clone** website developed using **HTML, CSS, and JavaScript**. This project recreates the basic design and user interface of the Amazon shopping website for learning and frontend development practice.

## 🔗 GitHub Repository

**Author:** [Alokkumar345](https://github.com/Alokkumar345)

**Project:** [AMAZONE_CLONE2025](https://github.com/Alokkumar345/AMAZONE_CLONE2025)

## 🚀 Features

* 🏠 Amazon-style homepage
* 🔍 Search bar UI
* 📦 Product sections
* 🛍️ Shopping/e-commerce style interface
* 📱 Responsive design
* 🎨 Amazon-inspired layout and styling
* ⚡ Interactive frontend components using JavaScript
* 🧭 Navigation sections

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactivity and dynamic behavior

## 💻 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Alokkumar345/AMAZONE_CLONE2025.git
```

### 2. Open the Project

Navigate to the project directory:

```bash
cd AMAZONE_CLONE2025
```

### 3. Run the Project

Open `index.html` in your browser.

You can also use **VS Code Live Server** to run the project locally.
